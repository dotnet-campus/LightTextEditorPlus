# README 面向使用方重构

## 背景与目标

文本库已开源，原 `README.md` 更偏框架开发说明，开篇即展示架构图、项目分层、调试机制和开发进度。目标是把 README 改成使用方优先：先看到构建状态、NuGet 包和最简用法，把框架设计与开发细节移到 Docs。

## 关键文件

- `README.md`
- `Docs/框架设计.md`
- `Docs/使用说明文档.md`
- `Directory.Build.props`
- `Docs/Knowledge/README.md`

## 主要决策

- README 顶部放构建状态和 NuGet 徽标，优先展示 AllInOne 包。
- 框架设计、平台进度、架构图、项目作用、调试机制迁到 `Docs/框架设计.md`，避免使用方一开始就看到内部细节。
- README 只保留安装、快速开始、功能列表和文档导航。
- 使用说明文档打入 NuGet 的 `docs/` 目录，方便后续 AI 阅读包内文档。
- 使用说明开头按 UI 框架说明该引用哪个包，文档自洽，不回链 README。
- 框架设计文档不回链 README。
- README 开篇不再用“可替换平台渲染和测量层”定位；包一览补充 AllInOne 与分层包的差别。

## 修改摘要

- 重写 `README.md`，面向使用方给出 WPF/Avalonia 安装命令、控件接入和最简 API。
- 新增 `Docs/框架设计.md`，承接原 README 中的架构与开发进度内容。
- 在 `Docs/使用说明文档.md` 开头按 UI 框架说明该引用哪个包，文档自洽，不回链 README。
- 在 `Directory.Build.props` 中将 `Docs/使用说明文档.md` 打包到 NuGet 的 `docs/` 路径。

## 验证方式

- 核对 README 链接指向现有文档。
- 核对 `PackageId` 与当前可发布包一致。
- 文档与打包配置变更，未改动代码行为，未运行单元测试。

## 后续建议

- 若仓库 GitHub 组织或仓库名与徽标 URL 不一致，发布后需校正构建状态徽标地址。
- NuGet 页面会使用根 README 作为包说明；包内完整使用说明位于 `docs/使用说明文档.md`。
